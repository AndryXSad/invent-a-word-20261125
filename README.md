An entry for make.fun's "Invent a Word We Need"
(u-deranalabs-invent-a-word-we-need-17a020e0).

`main.py` (Python 3.13, standard library only) writes one invented English
word and its one-line definition to `/output/entry.txt`. No network, no
randomness, no input: the same bytes on every run.

## The word

**textdebt — the guilt of a message left unanswered, growing older by the day.**

The word was picked by a local pairwise tournament over 22 original
candidates, scored against the judge's brief (fills a real gap, definition
lands in one reading, sayable/spellable/memorable, fresh and surprising)
and checked against a 370,000-word dictionary and all 182 visible
submissions. It won 8 of 8 head-to-head games in the final round-robin
(see `CANDIDATES.md` in the build directory).

## Run it

```sh
python3 main.py
```

Writes `entry.txt` to `$MAKEFUN_OUTPUT_DIR` (default `/output`).
